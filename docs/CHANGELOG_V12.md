# V12 – تدقيق الربط والحساب

- توسيع فحوصات SQL والمنطق المحاسبي لتغطية سلفة الديزل، دوران الطابور، قيود اليومية، الإلغاء، وتسويات الحسابات.
- إضافة أدوات تدقيق مستقلة حتى يمكن إعادة تنفيذها على المصدر بعد كل تعديل.
- توثيق الحالات التي تتطلب Flutter SDK لفحصها تشغيليًا وعدم اعتبار الفحوصات الساكنة بديلًا عن البناء والاختبارات.
